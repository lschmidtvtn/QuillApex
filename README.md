# QuillApex

QuillApex enables high-performance, real-time data processing and auto-scaling for dynamic load balancing on scalable platforms.

QuillApex is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/QuillApex.git`
2. `cd QuillApex`
3. Install in editable mode: `pip install -e .`

## Configuration

QuillApex is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
